# Code de conduite

Cette plateforme existe pour que les désaccords restent pacifiques. Le même esprit vaut pour ce dépôt.

- On critique les idées et le code, jamais les personnes.
- Pas d'insulte, de menace, de harcèlement ni de discrimination.
- On reformule ce que l'autre a dit avant de répondre, en cas de désaccord.
- Aucun débat partisan dans les tickets : le projet ne soutient aucun parti ni candidat.

Signalement : lettre@lafranceendebat.fr. Les mainteneurs peuvent modérer, fermer un échange ou exclure une personne.
