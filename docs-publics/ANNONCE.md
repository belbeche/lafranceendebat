# Textes d'annonce

Textes prêts à adapter pour annoncer l'ouverture du code. Relire les règles de chaque communauté avant de publier, et ne pas annoncer avant d'avoir activé le signalement privé des failles et changé les secrets.

## Français

**La France en Débat : une plateforme citoyenne open source de débat apaisé**

Nous ouvrons le code de La France en Débat, une plateforme où chacun peut débattre, proposer des mesures et suivre les engagements officiels, avec une modération stricte (ni insultes, ni menaces, ni haine) et des algorithmes de classement publics.

- Pile technique : Symfony 6.4, PHP 8.2, Bootstrap 5.
- Licence : AGPL-3.0. Tout le monde peut l'utiliser et la modifier ; une version modifiée proposée comme service en ligne doit rester ouverte.
- Vie privée : aucun traceur tiers, aucun pixel dans les e-mails, audience mesurée sans cookie, durées de conservation fixées.
- Tout est documenté : architecture, algorithmes, données personnelles.

Nous cherchons de l'aide sur : les tests, l'accessibilité, les traductions, la documentation et les outils de modération. Les premiers tickets sont étiquetés « good first issue ». Contribuer ne coûte rien et vos contributions restent sous AGPL.

Code : https://github.com/belbeche/lafranceendebat
Site : https://lafranceendebat.fr

## English

**La France en Débat: an open-source platform for peaceful, source-based public debate**

We are opening the code of La France en Débat, a civic platform where people debate, submit proposals and follow official commitments, with strict moderation (no insults, threats or hate) and public ranking algorithms.

- Stack: Symfony 6.4, PHP 8.2, Bootstrap 5.
- License: AGPL-3.0. Anyone can use and modify it; a modified version run as an online service must stay open.
- Privacy by design: no third-party trackers, no tracking pixels in e-mails, cookie-free audience measurement, fixed retention periods.
- Everything is documented: architecture, algorithms, personal data.

We are looking for help with tests, accessibility, translations, documentation and moderation tooling. Good first issues are labeled. Contributing is free and your contributions stay under AGPL.

Code: https://github.com/belbeche/lafranceendebat
Live site: https://lafranceendebat.fr
