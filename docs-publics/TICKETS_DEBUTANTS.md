# Tickets débutants

Ces tickets sont prêts à être créés sur GitHub avec l'étiquette `good first issue` (script : `scripts/github-setup.sh`). Chacun indique où modifier, le résultat attendu et le test.

1. **Ajouter des tests PHPUnit pour le filtre de modération** : `.github/good-first-issues/01-moderation-phpunit.md`
2. **Ajouter une intégration continue (GitHub Actions)** : `.github/good-first-issues/02-ci-github-actions.md`
3. **Traduire le document des algorithmes en anglais** : `.github/good-first-issues/03-translate-algorithms-en.md`
4. **Ajouter les propositions validées au sitemap.xml** : `.github/good-first-issues/04-sitemap-propositions.md`
5. **Auditer l'accessibilité du bandeau de consentement et de la navigation** : `.github/good-first-issues/05-accessibility-banner-nav.md`
6. **Fournir un environnement de développement Docker** : `.github/good-first-issues/06-docker-compose-dev.md`
7. **Créer une commande qui détecte les traductions manquantes** : `.github/good-first-issues/07-translations-check-command.md`
8. **Ajouter la balise noindex aux pages privées** : `.github/good-first-issues/08-noindex-private-pages.md`

Une fois un ticket pris, commentez « je m'en occupe » pour éviter les doublons. Lisez `CONTRIBUTING.md` et `docs-publics/ARCHITECTURE.md` avant de commencer.
