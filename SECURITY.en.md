# Security policy

[Français](SECURITY.md) | **English**

## Reporting a vulnerability
Write to **lettre@lafranceendebat.fr** with "SECURITY" in the subject, or use the private reporting of the forge (Security tab, "Report a vulnerability"). Please publish nothing before it is fixed.

We acknowledge receipt within 5 working days and keep you informed about the fix. You will be credited publicly if you wish.

## Scope
The code in this repository and the production site. Out of scope: volumetric denial of service, social engineering, tests on other members' accounts.

## Rules for testers
Do not read, change or delete other people's data. Use your own accounts. Stop as soon as you have proven the issue.

## What this repository deliberately does not contain
Keys, passwords, tokens, production configuration, member data. If you find any, report it: it is a vulnerability.
